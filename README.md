# Heavy Supplier Warehouse Analytics

Week 1 supply-chain analytics project covering warehouse data profiling, date cleaning, and preparation of 12 datasets for inventory and supplier analysis.

## Project Overview

This is my Week 1 project for the Heavy Supplier, Inventory and Warehouse Analytics internship. I reviewed the supplied warehouse and supply-chain CSV files, checked their quality, converted the date fields, and saved cleaned copies for the next stage.

## Project Structure

- `data/raw/`: Original CSV files. Keep these files untouched.
- `data/cleaned/`: Cleaned and validated datasets.
- `notebooks/`: Week 1 profiling and cleaning notebooks.
- `docs/`: Data dictionary, profiling report, and supplied field documentation.
- `sql/`: SQL scripts for a later phase.
- `outputs/`: Charts, dashboards, exported tables, and Power BI-ready files.

## Week 1 Work Completed

- Reviewed all 12 files in `data/raw`.
- Checked row counts, columns, data types, missing values, and duplicate rows.
- Converted the date columns to datetime values.
- Kept 2,370 blank `received_date` values because the related purchase orders were returned.
- Saved all 12 files in `data/cleaned`.
- Added the Week 1 documentation in `docs/`.
